# Бот учёта рабочего времени

Telegram-бот @Nookatcheckintime_bot: сотрудники отмечают приход в офисе по геолокации, пишут план на день, вечером отмечают статусы задач и уход (в офисе или «в полях»), а бот сообщает об этом в общий чат.

**Этап 1 — отметки:**
- подключение сотрудника по номеру телефона, роли: владелец, руководитель, сотрудник;
- кнопка «🏢 Я в офисе» — засчитывается только внутри круга 100 м от офиса, с расчётом опоздания;
- кнопка «🏁 Завершить день» — уход из офиса или «в полях» со ссылкой на 2ГИС;
- сообщения в общий чат о приходе и уходе; список сотрудников с отметками за сегодня.

**Этап 2 — задачи:**
- после прихода — вчерашние незакрытые задачи (оставить / убрать) и новые задачи текстом, каждая с новой строки;
- план на день уходит в общий чат; «📋 Мои задачи» (Начал, срок), «➕ Добавить задачу»;
- вечером статус по каждой задаче кнопками: ✅ Выполнено, 🔄 В работе, ⏳ Не успел, 🚧 Не по моей вине (с причиной), ❌ Отменена; комментарий по желанию, для «Отменена» и «Другое» — обязательно;
- итог задач добавляется к сообщению об уходе в общем чате;
- «📌 Поставить задачу» для руководителя: сотрудник получает её с кнопкой «👍 Принял»;
- алерт руководителю (только ему), если задача 2 рабочих дня подряд «Не успел», и отдельный алерт «Сотруднику нужна помощь» при «Не по моей вине»; кнопки «👌 Принял» и «❌ Отменить задачу».

**Этап 3 — отчёты, табель, напоминания:**
- «📊 Отчёты» (руководитель и владелец): за сегодня, вчера, неделю, месяц; неделя и месяц — с Excel-табелем (листы «Табель», «Подробно», «Задачи»);
- по расписанию: ежедневный отчёт в 19:00, недельный по понедельникам и месячный 1-го числа в 09:00 — руководителю и владельцу;
- «🗓 Табель»: выходной, больничный, отпуск, командировка, отгул на 1–14 дней, праздник для всех; исправление времени прихода и ухода с обязательной причиной; индивидуальный график сотрудника; сотрудник получает уведомление об изменениях; все правки — в журнале;
- напоминания: «вы ещё не отметились» через 15 мин после начала смены, «завершите день» через 30 мин после конца; сводка «ещё не отметились» в общий чат через 30 мин после начала;
- алерт о невыполненной задаче повторяется каждое рабочее утро, пока руководитель не нажмёт «Принял»;
- ночной бэкап базы владельцу в личный чат в 03:00.

**Дальше по плану:** пилот на 3–5 сотрудниках, перенос на бесплатный сервер (этап 4).

## 1. Подготовка (один раз)

1. **Токен бота.** В Telegram откройте @BotFather → `/mybots` → выберите @Nookatcheckintime_bot → *API Token*. Токен — это секрет: никому его не отправляйте и не загружайте в GitHub.
2. **Файл настроек.** Скопируйте `.env.example` в `.env` и заполните:
   - `BOT_TOKEN` — токен из шага 1;
   - `OWNER_PHONE` — ваш номер телефона, например `+996555123456`;
   - `OFFICE_LAT`, `OFFICE_LON` — координаты офиса (сейчас стоят временные);
   - `WORK_START`, `WORK_END`, `GRACE_MINUTES`, `WORK_DAYS` — график.

## 2. Запуск

### Вариант А — Docker (рекомендуется для сервера)

```bash
git clone https://github.com/sezimai0088-maker/sezimwork-1.git
cd sezimwork-1
cp .env.example .env      # и заполните .env
docker compose up -d --build
docker compose logs -f    # посмотреть, что бот запустился
```

Обновить бота после изменений в репозитории:

```bash
git pull && docker compose up -d --build
```

### Вариант Б — без Docker (для проверки на своём компьютере)

Нужен Python 3.12 или новее.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m bot.main
```

Пока программа открыта — бот работает. Закрыли окно — бот остановился.

## 3. Первая настройка в Telegram

1. Откройте бота, нажмите **«Запустить»** и **«📱 Отправить мой номер»** — вы станете владельцем (номер должен совпадать с `OWNER_PHONE`).
2. Создайте общий чат, добавьте туда бота, сделайте его администратором и отправьте в чате команду `/bind_chat`.
3. Добавьте людей командами в личном чате с ботом:
   - сотрудник: `/add +996555123456 Айбек Асанов`
   - руководитель: `/add_manager +996555000000 Нурлан Касымов`
   - ещё один владелец (например, программист): `/add_owner +996555000001 Имя Фамилия`
4. Отправьте каждому ссылку `https://t.me/Nookatcheckintime_bot` — он нажмёт «Запустить» и «📱 Отправить мой номер».

Все команды владельца — `/admin`. Отключить сотрудника — `/remove +996555123456` (история отметок сохраняется).

## 4. Как это выглядит для сотрудника

- Утром в офисе: **«🏢 Я в офисе»** → телефон один раз спросит разрешение на геолокацию → отметка.
- Вне круга 100 м отметка не засчитывается, бот пишет расстояние до офиса.
- Сразу после прихода бот просит написать задачи на день — **каждую с новой строки**, одним сообщением → «✅ Готово» → «✅ Всё верно».
- Вечером: **«🏁 Завершить день»** → статус каждой задачи кнопками → «✅ Отправить» → **«📍 Отправить местоположение»** → бот сам определит, в офисе или в полях.

## 5. Правила

| Что | Как считается |
| --- | --- |
| Геозона | Круг радиусом `OFFICE_RADIUS_M` (100 м) вокруг координат офиса |
| Погрешность GPS | Если больше `MAX_ACCURACY_M` (100 м) — бот просит повторить |
| Опоздание | Если пришёл позже начала смены больше чем на `GRACE_MINUTES`, опоздание считается от начала смены: 09:07 при начале 09:00 → 7 мин |
| Выходной | В нерабочие дни опоздание не считается |
| Защита | Не принимаются пересланные геопозиции и место, выбранное на карте вручную |
| Перенос задач | «В работе», «Не успел», «Не по моей вине» переносятся на завтра той же задачей; «Выполнено» и «Отменена» закрываются |
| Алерт | `ALERT_DAYS` (2) рабочих дня подряд «Не успел» (или «В работе» после срока) → алерт руководителю; повторяется каждое рабочее утро до «Принял» |
| Особый день | В выходной, больничный, отпуск, командировку, отгул и праздник опоздание и неявка не считаются |
| Исправления | Руководитель меняет время прихода/ухода только с причиной; опоздание и часы пересчитываются; запись попадает в журнал |
| Расписание | Время отчётов, напоминаний и бэкапа — в `.env` (`DAILY_REPORT_TIME`, `WEEKLY_REPORT_TIME`, `CHECKIN_REMINDER_MIN`, `MORNING_SUMMARY_MIN`, `CHECKOUT_REMINDER_MIN`, `BACKUP_TIME`) |

## 6. Запуск на бесплатном сервере Google Cloud (работает круглосуточно)

### 6.1. Создать сервер (один раз, ≈10 минут)
1. Откройте https://console.cloud.google.com, войдите через Google и добавьте банковскую карту — она нужна только для проверки, в пределах бесплатного лимита деньги не списываются.
2. **Compute Engine → VM instances → Create instance**:
   - Name: `attendance-bot`
   - Region: **us-central1** (бесплатно только в регионах США: us-central1, us-west1, us-east1)
   - Machine type: **e2-micro**
   - Boot disk: **Change → Ubuntu 24.04 LTS**, тип **Standard persistent disk**, 10–30 ГБ
3. **Create**, подождите минуту.

### 6.2. Установить бота одной командой
1. **Сначала остановите бота на ноутбуке** (`Ctrl + C`) — один и тот же бот не может работать в двух местах сразу.
2. В списке серверов нажмите **SSH** напротив `attendance-bot` — откроется консоль в браузере.
3. Вставьте команду (правой кнопкой мыши или `Ctrl + Shift + V`) и нажмите Enter:
   ```
   curl -fsSL https://raw.githubusercontent.com/sezimai0088-maker/sezimwork-1/main/deploy/install.sh | bash
   ```
4. Скрипт сам установит всё нужное и задаст вопросы: токен бота, ваш номер, координаты офиса, время работы.
5. В конце появится «Готово! Бот работает круглосуточно».

### 6.3. Полезные команды на сервере
| Что | Команда |
| --- | --- |
| Посмотреть журнал бота | `cd ~/sezimwork-1 && sudo docker compose logs -f --tail 50` (выйти — `Ctrl + C`) |
| Обновить бота до новой версии | `bash ~/sezimwork-1/deploy/update.sh` |
| Изменить настройки (координаты, время) | `nano ~/sezimwork-1/.env`, сохранить `Ctrl + O`, `Enter`, выйти `Ctrl + X`, затем `bash ~/sezimwork-1/deploy/update.sh` |
| Восстановить базу из бэкапа | загрузить файл через ⚙ → Upload file, затем `bash ~/sezimwork-1/deploy/restore.sh ~/backup_ГГГГ-ММ-ДД.db` |
| Перенести базу с ноутбука | загрузить `data\bot.db` с ноутбука через ⚙ → Upload file, затем `bash ~/sezimwork-1/deploy/restore.sh ~/bot.db` |

Бот сам запускается после перезагрузки сервера. Каждую ночь в 03:00 копия базы приходит владельцу в Telegram.

## 7. Пилот (1–2 недели, 3–5 сотрудников)

**Перед стартом**
- [ ] Бот работает на сервере, на ноутбуке остановлен
- [ ] В `.env` — настоящие координаты офиса (с. Чапаев, ул. Төлөнов, 12), а не тестовые
- [ ] Общий чат подключён (`/bind_chat`), руководитель добавлен (`/add_manager`)
- [ ] 3–5 сотрудников добавлены (`/add`), у каждого бот на **телефоне**, номер подтверждён

**Первый день — подключить каждого лично (5 минут на человека)**
- [ ] Включить геолокацию на телефоне, нажать «🏢 Я в офисе» вместе с ним
- [ ] Показать: задачи пишутся каждая с новой строки → «✅ Готово» → «✅ Всё верно»
- [ ] Показать вечерний «🏁 Завершить день»

**Что проверить за пилот**
- [ ] Все ли проходят геозону внутри здания (если нет — увеличить `OFFICE_RADIUS_M` или `MAX_ACCURACY_M`)
- [ ] Приходят ли напоминания, сводка в 09:30, отчёт в 19:00, бэкап ночью
- [ ] Понятны ли сотрудникам кнопки и тексты — записывать вопросы
- [ ] Отчёт за неделю в понедельник и Excel-табель открываются и понятны бухгалтерии

**После пилота** — собрать замечания, поправить тексты и настройки, добавить остальных сотрудников.

## 8. Как обновить бота на ноутбуке

1. Остановите бота: в чёрном окне `Ctrl + C`.
2. Скачайте свежий код (Code → Download ZIP) и распакуйте **поверх** старой папки, заменив файлы. Файл `.env`, папки `.venv` и `data` останутся — их в архиве нет.
3. В чёрном окне в папке проекта:
   ```
   .venv\Scripts\activate
   pip install -r requirements.txt
   python -m bot.main
   ```

Новые таблицы в базе создаются сами при запуске, старые отметки сохраняются.

## 9. Для разработчика

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

Структура:

```
bot/
  main.py            запуск, long polling
  config.py          настройки из .env
  models.py          таблицы: сотрудники, отметки, задачи, итоги задач, алерты
  task_rules.py      правила задач: статусы, перенос, счётчики дней, разбор текста
  schedule.py        графики работы (общий и индивидуальный)
  scheduler.py       расписание: напоминания, отчёты, повтор алертов, бэкап
  excel.py           Excel-табель
  report_texts.py    тексты отчётов
  geo.py             расстояние до офиса, геозона, ссылка 2ГИС
  worktime.py        опоздания, ранний уход, отработанное время
  texts.py           все тексты и названия кнопок
  keyboards.py       кнопки
  handlers/          обработка сообщений: подключение, отметки, команды владельца
  services/          логика: сотрудники, отметки, отправка в общий чат
tests/               автотесты
```

База — один файл SQLite в папке `data/`. Для бэкапа достаточно скопировать `data/bot.db`.
