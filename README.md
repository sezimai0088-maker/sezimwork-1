# Бот учёта рабочего времени

Telegram-бот @Nookatcheckintime_bot: сотрудники отмечают приход в офисе по геолокации и уход (в офисе или «в полях»), а бот сообщает об этом в общий чат.

**Сейчас готово (этап 1):**
- подключение сотрудника по номеру телефона, роли: владелец, руководитель, сотрудник;
- кнопка «🏢 Я в офисе» — засчитывается только внутри круга 100 м от офиса, с расчётом опоздания;
- кнопка «🏁 Завершить день» — уход из офиса или «в полях» со ссылкой на 2ГИС;
- сообщения в общий чат о приходе и уходе;
- список сотрудников с отметками за сегодня для руководителя.

**Дальше по плану:** задачи на день и статусы (этап 2), отчёты, табель и алерты (этап 3), пилот (этап 4).

---

## 1. Подготовка (один раз)

1. **Токен бота.** В Telegram откройте @BotFather → `/mybots` → выберите @Nookatcheckintime_bot → *API Token*. Токен — это секрет: никому его не отправляйте и не загружайте в GitHub.
2. **Файл настроек.** Скопируйте `.env.example` в `.env` и заполните:
   - `BOT_TOKEN` — токен из шага 1;
   - `OWNER_PHONE` — ваш номер телефона, например `+996555123456`;
   - `OFFICE_LAT`, `OFFICE_LON` — координаты офиса (сейчас стоят временные);
   - `WORK_START`, `WORK_END`, `GRACE_MINUTES`, `WORK_DAYS` — график.

## 2. Запуск

### Вариант А — Docker (рекомендуется для сервера)

```bash
git clone https://github.com/sezimai0088-maker/sezimwork-1.git
cd sezimwork-1
cp .env.example .env      # и заполните .env
docker compose up -d --build
docker compose logs -f    # посмотреть, что бот запустился
```

Обновить бота после изменений в репозитории:

```bash
git pull && docker compose up -d --build
```

### Вариант Б — без Docker (для проверки на своём компьютере)

Нужен Python 3.12 или новее.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m bot.main
```

Пока программа открыта — бот работает. Закрыли окно — бот остановился.

## 3. Первая настройка в Telegram

1. Откройте бота, нажмите **«Запустить»** и **«📱 Отправить мой номер»** — вы станете владельцем (номер должен совпадать с `OWNER_PHONE`).
2. Создайте общий чат, добавьте туда бота, сделайте его администратором и отправьте в чате команду `/bind_chat`.
3. Добавьте людей командами в личном чате с ботом:
   - сотрудник: `/add +996555123456 Айбек Асанов`
   - руководитель: `/add_manager +996555000000 Нурлан Касымов`
4. Отправьте каждому ссылку `https://t.me/Nookatcheckintime_bot` — он нажмёт «Запустить» и «📱 Отправить мой номер».

Все команды владельца — `/admin`. Отключить сотрудника — `/remove +996555123456` (история отметок сохраняется).

## 4. Как это выглядит для сотрудника

- Утром в офисе: **«🏢 Я в офисе»** → телефон один раз спросит разрешение на геолокацию → отметка.
- Вне круга 100 м отметка не засчитывается, бот пишет расстояние до офиса.
- Вечером: **«🏁 Завершить день»** → **«📍 Отправить местоположение»** → бот сам определит, в офисе или в полях.

## 5. Правила

| Что | Как считается |
| --- | --- |
| Геозона | Круг радиусом `OFFICE_RADIUS_M` (100 м) вокруг координат офиса |
| Погрешность GPS | Если больше `MAX_ACCURACY_M` (100 м) — бот просит повторить |
| Опоздание | Если пришёл позже начала смены больше чем на `GRACE_MINUTES`, опоздание считается от начала смены: 09:07 при начале 09:00 → 7 мин |
| Выходной | В нерабочие дни опоздание не считается |
| Защита | Не принимаются пересланные геопозиции и место, выбранное на карте вручную |

## 6. Для разработчика

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

Структура:

```
bot/
  main.py            запуск, long polling
  config.py          настройки из .env
  models.py          таблицы: сотрудники, отметки, настройки
  geo.py             расстояние до офиса, геозона, ссылка 2ГИС
  worktime.py        опоздания, ранний уход, отработанное время
  texts.py           все тексты и названия кнопок
  keyboards.py       кнопки
  handlers/          обработка сообщений: подключение, отметки, команды владельца
  services/          логика: сотрудники, отметки, отправка в общий чат
tests/               автотесты
```

База — один файл SQLite в папке `data/`. Для бэкапа достаточно скопировать `data/bot.db`.
